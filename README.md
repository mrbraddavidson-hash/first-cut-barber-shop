# First Cut Barber Shop — Listowel, Ontario

Official website codebase for **First Cut Barber Shop**, located at 130 Inkerman St West in downtown Listowel, Ontario.

## 💈 Features
- **Design System:** Signboard Navy (`#162544`), Barber Crimson (`#B22222`), and Crisp Barber White (`#FFFFFF`) with static barber pole candy-stripe ribbons.
- **Dynamic Walk-In Radar:** Client-side JavaScript live status calculation checking open/closed state against current local Ontario time.
- **Service & Rate Tariff:** Transparent pricing for adult cuts ($24), seniors ($20), boys ($18), beard trims ($12), and buzz cuts ($16).
- **Storefront Photography:** Real storefront assets from 130 Inkerman St W and the authentic window humor motto (*"Dogs Welcome, People Tolerated"*).
- **Responsive Mobile First:** Clean streamlined header, sticky mobile quick-call bar, and interactive map embed.

## 🚀 Deployment
Deployed via Cloudflare Pages and hosted on GitHub.
